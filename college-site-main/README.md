# Кулинарная студия
Сайт кулинарной студии «Вкусные уроки» — адаптивный веб-ресурс для просмотра расписания мастер-классов, бронирования мероприятий и публикации рецептов. Создан как учебный проект для демонстрации навыков UX/UI дизайна, верстки и работы с формами записи.
# Название проекта
Кулинарная студия «Вкусные уроки»
## Описание
Веб-сайт кулинарной студии для просмотра расписания мастер-классов, заказа мероприятий и публикации рецептов. Проект создан для демонстрации навыков разметки и стилизации веб-страниц.
